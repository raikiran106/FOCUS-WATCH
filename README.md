# 🎯 FocusWatch

> A distraction-free YouTube player designed for focused and uninterrupted learning.

FocusWatch is a lightweight web application that provides a clean interface for watching YouTube videos without unnecessary distractions.

## ✨ Features

- 🎥 Watch YouTube videos directly in the application
- 🔗 Accept YouTube video URLs
- 🔍 Automatically extract the YouTube video ID
- ▶️ Load videos directly into an embedded player
- ⚠️ Validate empty and invalid YouTube links
- 📱 Responsive 16:9 video player
- 🎨 Minimal and distraction-free interface

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure and semantic layout |
| CSS3 | Styling and responsive design |
| JavaScript | URL processing and player functionality |
| YouTube Embed | Video playback |
