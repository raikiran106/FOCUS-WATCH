🎯 FocusWatch

A clean and distraction-free YouTube player for focused learning and
watching.

 ✨ Features

- 🎥 Play YouTube videos
- 📋 Support YouTube playlists
- 🔗 Extract YouTube video IDs automatically
- ▶️ Play videos directly in the player
- 📱 Responsive 16:9 player
- ⚠️ Input validation and error handling
- 🎨 Clean, distraction-free interface

 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API
