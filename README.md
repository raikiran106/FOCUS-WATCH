# 🎯 FocusWatch

**A distraction-free YouTube player designed for focused and uninterrupted learning.**

FocusWatch provides a clean and simple interface for watching YouTube videos without unnecessary distractions.

## ✨ Features

* 🎥 Play YouTube videos directly in the browser
* 🔗 Accept YouTube video links
* ▶️ Simple and intuitive video playback
* 📱 Responsive 16:9 video player
* ⚠️ Input validation and error handling
* 🎨 Clean and distraction-free interface

## 🛠️ Tech Stack

* **HTML5** — Page structure
* **CSS3** — Styling and responsive layout
* **JavaScript** — Functionality and YouTube URL handling
* **YouTube IFrame Player** — Video playback

## 📂 Project Structure

FocusWatch/

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
```

### 2. Open the project

Open the project folder in VS Code.

### 3. Run FocusWatch

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
